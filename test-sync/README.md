# Изолированный тест синхронизации прогресса

Эта страница не подключена к интерфейсу основной игры и нужна только для ручной проверки Telegram Mini App → Google Apps Script → Google Sheets.

## Публикация без замены основной игры

Сайт проекта: `https://ilzgm.github.io/panalytics_simulator_bot/`.

GitHub Pages публикует одну настроенную ветку и папку (или результат одного Pages workflow). Файлы в feature-ветке не становятся доступными на сайте автоматически. По официальной документации можно выбрать любую ветку как источник публикации, но переключение текущего сайта на тестовую ветку заменит публикуемую версию и потому здесь не подходит. Источник: https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site

Безопасный вариант для этого проекта — добавить только папку `test-sync/` в `main` после проверки PR. Это добавит отдельный путь `/test-sync/`, но не меняет `index.html`, сценарии эпизодов или основную логику игры. После слияния и успешной публикации ожидаемый адрес: `https://ilzgm.github.io/panalytics_simulator_bot/test-sync/`.

## Проверка

1. После публикации открой тестовую страницу через Telegram Web App кнопку бота. Если бот открывает фиксированный URL, для теста потребуется временно указать URL страницы `/test-sync/` в отдельной тестовой кнопке/команде бота. Не меняй постоянную кнопку запуска основной игры.
2. Нажми «Проверить облачный прогресс». Успех означает, что клиент получил подтверждённую сессию и ответ API.
3. Если в таблице ещё нет строки для аккаунта, сначала попробуй прочитать прогресс, затем нажми «Записать завершение эпизода 1».
4. Нажми «Попробовать завершить эпизод 2». Если эпизод 1 не завершён, сервер должен отказать с `previous_episode_required`. Если эпизод 1 уже завершён, эта кнопка завершит эпизод 2.
5. Открой страницу на другом устройстве под тем же Telegram-аккаунтом и проверь, что завершённые эпизоды совпадают.

**Важно:** тестовые действия изменяют реальную таблицу Google Sheets и привязаны к Telegram-аккаунту. Здесь нет кнопки сброса. Не отправляй в чат токен бота или Telegram `initData`.

## Ограничения

- Эта страница не является изолированной тестовой базой: она использует ту же таблицу и тот же Apps Script deployment, что и текущая реализация синхронизации.
- Проверка требует открытия из Telegram, потому что обычный браузер не предоставляет подписанный Telegram `initData`.
- Реальную работу POST-сессии, запись в таблицу и перенос между устройствами ещё нужно подтвердить ручным запуском; наличие кода не означает, что интеграция уже проверена.
